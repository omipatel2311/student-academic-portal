# Student Academic Portal

## Project Overview
Student Academic Portal is a web-based project developed as part of the Web Development Framework (WDF) subject at CHARUSAT University.

The main goal of this project is to provide a single platform where students can access important academic information and services.

## Project Objectives
- Create a user-friendly student portal.
- Design responsive web pages.
- Implement form validation and interactive features.
- Manage student and event information.
- Integrate frontend and backend technologies.
- Store and manage data using a database.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- JSON
- PHP
- MySQL
- Git and GitHub
- XAMPP
