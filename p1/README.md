# StudentHub Portal – Web Development Practicals

## 1. Project Description

StudentHub is a web-based student portal developed as part of the Web Development Frameworks practical course at CHARUSAT University.

The portal is designed to provide students with easy access to academic information, college events, assignments, attendance, results, timetable and other useful resources through a structured and user-friendly interface.

This project covers the complete web development process, including requirement analysis, HTML page design, responsive CSS, JavaScript interactivity, JSON data handling, PHP form processing, MySQL database connectivity and CRUD operations.

## 2. Project Objectives

- To design a structured and user-friendly student portal.
- To create accessible and semantically correct HTML pages.
- To develop responsive layouts using CSS.
- To implement interactive features using JavaScript.
- To retrieve and display JSON data using the Fetch API.
- To process forms using PHP with server-side validation.
- To design and connect a MySQL database.
- To implement secure registration and login functionality.
- To perform student and event management using CRUD operations.
- To organize and maintain project code using Git and GitHub.

## 3. Main Features

- Student registration and login.
- Student dashboard and profile.
- Academic information and attendance.
- Assignments and study resources.
- Results and timetable.
- College events and announcements.
- Form validation and user-friendly error messages.
- Dynamic data rendering from JSON files.
- PHP form processing and file storage.
- MySQL database connectivity.
- Secure user registration and session management.
- Student and event CRUD operations.
- Search and filter functionality.
- Event poster upload with file validation.

## 8. Development and Execution

- HTML, CSS and JavaScript practicals can be developed using Visual Studio Code.
- Frontend pages can be tested in a modern web browser.
- JSON Fetch API practicals can be tested using a local development server.
- PHP practicals can be executed using XAMPP Apache.
- Database practicals require MySQL and may use phpMyAdmin.
- Git and GitHub are used to manage and submit the project source code.
